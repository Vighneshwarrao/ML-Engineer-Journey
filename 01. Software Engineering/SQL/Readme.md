# SQL 10-Day Learning Plan

| Day | Topics |
|---|---|
| **1** | `SELECT`, `WHERE`, `ORDER BY`, `DISTINCT`, `LIMIT` |
| **2** | Operators, `LIKE`, `IN`, `BETWEEN`, `NULL` |
| **3** | Aggregate Functions, `GROUP BY`, `HAVING` |
| **4** | `CASE`, String Functions, Date Functions |
| **5** | `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `SELF JOIN` |
| **6** | Subqueries, Correlated Subqueries, `EXISTS` |
| **7** | `UNION`, `UNION ALL`, CTEs |
| **8** | Window Functions — `ROW_NUMBER`, `RANK`, `DENSE_RANK` |
| **9** | Window Functions — `LAG`, `LEAD`, Running Totals, Moving Averages |
| **10** | Mixed **Interview-Level SQL Problems** |

## Goal

By the end of these 10 days, I should be comfortable with:

- Writing SQL queries from scratch
- Filtering and sorting data
- Aggregating and grouping data
- Working with multiple tables using joins
- Using subqueries and CTEs
- Understanding `EXISTS` and correlated subqueries
- Applying window functions
- Solving common **SQL interview problems**
